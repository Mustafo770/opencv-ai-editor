# AI Image Editor

Редактор изображений с управлением на естественном языке. Пользователь пишет команду по-русски, локальная языковая модель через LM Studio переводит её в вызов OpenCV, результат отображается в графическом интерфейсе.

## Технологии

- **Python 3.9+**
- **LM Studio** — локальный LLM-сервер
- **OpenCV** — обработка изображений
- **Tkinter** — графический интерфейс
- **Pillow** — отображение изображений в Tkinter

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/ваш-ник/ai-image-editor.git
cd ai-image-editor
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Настроить LM Studio:

1. Скачать [LM Studio](https://lmstudio.ai) и установить
2. Загрузить любую Instruct-модель (рекомендуется Mistral 7B или LLaMA 3.1 8B)
3. Открыть вкладку Local Server и нажать Start Server
4. Сервер запустится на `http://localhost:1234`

## Запуск

```bash
python app.py
```

## Использование

1. Нажать кнопку "Открыть изображение" и выбрать файл (`.jpg`, `.png`, `.bmp`, `.webp`, `.tiff`)
2. Ввести команду на русском языке в текстовое поле
3. Нажать "Выполнить" или клавишу Enter
4. Результат появится на экране

## Поддерживаемые команды

Программа понимает свободный текст, примеры:

| Команда | Действие |
|---|---|
| Поверни на 90 градусов | поворот по часовой стрелке |
| Сделай чёрно-белым | перевод в оттенки серого |
| Размой | гауссово размытие |
| Увеличь яркость на 50 | яркость +50 |
| Измени размер до 800 на 600 | масштабирование |
| Отрази по горизонтали | зеркальное отражение |
| Выдели красный канал | обнуление синего и зелёного каналов |
| Выдели края | алгоритм Canny |
| Сброс | возврат к исходному изображению |

## Структура проекта

```
ai-image-editor/
├── app.py            # весь код приложения
├── requirements.txt  # зависимости
└── README.md
```

Код разделён на три независимых блока:

- `ask_llm()` — отправляет текст пользователя в LM Studio, получает JSON с командой
- `apply_command()` — читает JSON и вызывает соответствующую функцию OpenCV
- `class App` — графический интерфейс на Tkinter

## Как работает связка LLM и OpenCV

Пользователь вводит текст, например "Размой изображение". Функция `ask_llm()` отправляет его в LM Studio вместе с системной инструкцией отвечать строго в JSON. Модель возвращает:

```json
{"command": "blur", "strength": 11}
```

Функция `apply_command()` читает поле `command` и вызывает:

```python
cv2.GaussianBlur(image, (11, 11), 0)
```

Запрос к модели выполняется в отдельном потоке, чтобы интерфейс не зависал во время ожидания ответа.

## Возможные проблемы

**LM Studio не отвечает** — убедитесь, что сервер запущен на порту 1234 (вкладка Local Server > Start Server).

**Модель возвращает не JSON** — смените модель на Instruct-версию, они лучше следуют инструкциям формата ответа.

**Изображение не открывается** — на Windows OpenCV иногда не читает пути с кириллицей, переместите файл в папку с латинским названием.
